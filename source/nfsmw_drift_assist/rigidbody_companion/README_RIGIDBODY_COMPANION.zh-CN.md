# 0.9.5 严格基线 + 刚体补速附加模块

本目录的发布方式把两个要求分开处理：

- `nfsmw_drift_assist_alpha.asi` 是历史 0.9.5 文件的逐字节副本，SHA-256
  `212372FB93026BAAE61F7E6A642F8C830B6EA1091CBEF686C44B7AD4418D089F`。
- `nfsmw_drift_assist_rigidbody.asi` 是独立附加模块，只替换
  `IRigidBody` 虚表 slot 39（`Accelerate`）。它不安装 0.9.5 已使用的输入或物理钩子，
  因而不会改变 0.9.5 的自动反打状态机、转向速率或镜头代码。

## 安装

完全退出游戏，将以下四个文件放入游戏 `scripts` 目录：

1. `nfsmw_drift_assist_alpha.asi`
2. `nfsmw_drift_assist_rigidbody.asi`
3. `drift_assist.ini`
4. 本说明（可选）

不要再同时放入 0.9.6 以后生成的同名 Alpha ASI，也不要与旧的刚体实验诊断版同时加载。

## 补速条件

附加模块只在已经拉过手刹并确认车辆进入持续侧滑、玩家身份和刚体链完整、至少两个轮胎
接地、有油门且没有刹车时调用 `Accelerate`。车辆换出、物理对象失效或严格读回失败后，
本进程的补速 writer 会故障关闭；历史 0.9.5 方向辅助仍保持原样。

补速沿车头前向施加，名义目标为 `5.25 m/s^2`，所有速度段统一乘 `0.80`，所以低速
有效目标为 `4.20 m/s^2`。速度衰减曲线使用整车线速度：

| 车速 | 相对名义目标 | 相对 5.25 的实际输出 |
| --- | ---: | ---: |
| `<=70 km/h` | 100% | 80% |
| `70-125 km/h` | 100% 到 50% | 80% 到 40% |
| `125-150 km/h` | 50% 到 15% | 40% 到 12% |
| `150-170 km/h` | 15% 到 0% | 12% 到 0% |
| `>=170 km/h` | 0% | 0% |

附加模块保留约 1 秒渐入、约 0.25 秒渐出和每次调用的速度增量上限。slot 39 是所有刚体
共用的虚表入口，模块会缓存已核验的玩家车辆身份（约 100 ms 重检一次），因此交通车辆
和场景刚体不会触发逐调用的全池扫描；换车或对象链变化会在下一次重检时刷新。初始化在
speed.exe 门禁通过后，最多等待 30 秒让物理虚表完成，未匹配到目标时保持禁用。

每次补速都在调用前后读取刚体速度，只有前向投影、总增量和正交残差同时通过才记为成功。
车身基向量会在标准化前检查真实长度和正交性；detour 还带线程本地重入保护，避免游戏
内部嵌套 Accelerate 调用重复补速。日志前缀为 `[nfsmw_drift_rigidbody]`。

## 兼容边界

该模块只接受已核验的 32 位 `speed.exe`（刚体虚表 `0x008AC880`、slot 39、
`Accelerate` RVA `0x00299E10`，入口字节
`8B 41 30 8B 00 8A 48 5D 84 C9 75 2A`）。配置、虚表、玩家归属或对象链不匹配时会
拒绝安装，不会尝试未经验证的地址。它是整车刚体速度增量，不是轮胎抓地力或原生传动扭矩
倍率。

当前环境只能完成静态构建和规划器回归测试，不能代替游戏内实机验证。出现异常加速、
侧翻、闪退或无法退出漂移时，应立即退出游戏并移除附加 ASI；历史 0.9.5 文件本身不会被
改写。
